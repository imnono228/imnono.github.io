# 表格驱动的个人主页

该网站会在浏览器中读取同目录下的 `网站内容.xlsx`，页面内容不写死在 HTML 中。

## 更新内容

1. 在 `网站内容.xlsx` 的第一行填写模块名称；每一列会自动成为一个页面模块。
2. 在该列的后续单元格填写文字，换行和空行会在网页中保留为段落结构。
3. 图片单独放在一个单元格中，填写图片文件名（如 `photo.jpg`），并把图片与 Excel 文件放进同一目录。网页会自动识别常见图片格式并自适应裁切、缩放。
4. 新增一列会自动生成新的导航和内容区；新增行也会自动显示。文字和相邻图片会并排显示，小屏幕则自动改为纵向布局。

## 部署到 GitHub Pages

将以下文件上传到 GitHub 仓库的根目录：

- `index.html`
- `网站内容.xlsx`
- 表格内引用的所有图片文件

然后在仓库的 **Settings → Pages** 中选择 `Deploy from a branch`，设置为 `main` 分支和 `/ (root)` 目录。每次改完表格或图片后，重新上传同名文件即可更新网页。

本地预览请使用静态网页服务器（例如 VS Code 的 Live Server）；直接双击 `index.html` 时，浏览器可能会阻止网页读取同目录的 Excel 文件。
